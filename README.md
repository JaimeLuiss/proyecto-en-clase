![Foto de perfil](./public/images/foto.jpg)


## Descripción

Mi Perfil es una aplicación web desarrollada con Laravel que presenta
información personal, intereses, habilidades y metas académicas y
profesionales.

El proyecto fue desarrollado como parte del taller de desarrollo backend
con Laravel.

## Tecnologías utilizadas

- PHP 8.5
- Laravel 13
- Blade
- HTML5
- CSS3
- Git
- GitHub
- SQLite

## Funcionalidades

La aplicación cuenta con las siguientes secciones:

- Perfil personal
- Intereses
- Habilidades
- Metas

Todas las secciones cuentan con un menú de navegación que permite
desplazarse entre las diferentes páginas.
